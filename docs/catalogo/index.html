Rótulo texto/rotulo

Rótulo de campo. `para` liga ao `id` do campo (clicar no rótulo foca o campo).

Props

PropTipoObrigatóriaPadrãoDescrição
paratextonão
textotextosim

Exemplos

Rótulo de um campo

Como declarar
{
  "bloco": "layout/pilha",
  "props": {
    "gap": 4
  },
  "slots": {
    "filhos": [
      {
        "bloco": "texto/rotulo",
        "props": {
          "texto": "Nome",
          "para": "nome"
        }
      },
      {
        "bloco": "entrada/texto",
        "id": "nome",
        "props": {
          "placeholder": "Seu nome"
        }
      }
    ]
  }
}
