# Idiomas (i18n)

O template de uma página **só leva chaves**; os textos de cada idioma vivem em **catálogos** (`kind: traducao`), separados da página. Trocar ou acrescentar um idioma não mexe em nenhuma página.

## Catálogo de tradução
```json
{ "kind": "traducao", "id": "loja", "versao": "1.0.0", "spec": {
  "padrao": "pt-BR",
  "mensagens": {
    "pt-BR": { "home.titulo": "Objetos de beleza serena", "sacola.itens": "{n, plural, =0 {Sacola vazia} one {# peça} other {# peças}}" },
    "en":    { "home.titulo": "Objects of quiet beauty",   "sacola.itens": "{n, plural, =0 {Bag is empty} one {# item} other {# items}}" } } } }
```
- Idiomas são tags **BCP 47** (`pt`, `pt-BR`, `en`). `padrao` é o idioma de referência: **toda chave nasce nele** (uma chave só em `en` é erro) e é o que vale quando falta a tradução.
- Falta de tradução **não** é erro: cai no idioma-base (`pt-PT` → `pt-BR`/`pt`), depois no `padrao`. Um idioma sem catálogo nenhum (`fr`) também cai no padrão.
- Catálogos seguem a cascata de sempre (tenant → segmento → core), com versões e releases.

## Nas páginas: `t("chave")`
A página lista os catálogos em `spec.traducoes` e usa `t(...)` em qualquer expressão ou template (título, props, `se`, `repetir`, ações):
```json
{ "spec": { "titulo": "{t(\"home.titulo\")}", "traducoes": ["loja"], "raiz": { "bloco": "texto/paragrafo",
  "props": { "texto": "{t(\"sacola.itens\", objeto([[\"n\", tamanho(estado.itens)]]))}" } } } }
```
- A chave é **texto literal** (não pode ser calculada): o compilador troca `t("k", params)` por `traduz(idioma, {pt-BR: …, en: …, "*": <padrão>}, params)` **embutindo só as mensagens que a página usa**. Resultado: SSR, cliente, estático e AOT escrevem o mesmo texto, sem consulta em tempo de execução, e a página não carrega mensagem que não usa.
- Erros de compilação com caminho e dica: chave inexistente (com "quis dizer"), chave calculada, página sem `traducoes`, catálogo inexistente e **ICU inválido** em qualquer idioma da chave usada.

## Mensagens: ICU MessageFormat (subconjunto)
`{nome}` · `{n, number}` · `{n, plural, =0 {…} one {# …} other {# …}}` (regras do **CLDR** via `Intl.PluralRules`; `#` é o número formatado no idioma) · `{x, select, a {…} other {…}}` · `''` é um apóstrofo e `'{…}'` é texto literal. O ramo `other` é obrigatório. Mensagem malformada volta como está (a função é total).

## Funções
`traduz(idioma, mensagens, params?)`, `loc(idioma, valor)` (dados que trazem o texto em vários idiomas: `{ "pt-BR": "Vaso", "en": "Vase" }`) e `qmoeda(valor, idioma)` (reais no formato do idioma: `R$ 1.234,50` / `R$1,234.50`). Ver `docs/funcoes.md`.

## Idioma da requisição e seletor
Com `idiomas` e `idiomaPadrao` no nó `tenant`, a rota escolhe o idioma (`/ola` é o padrão; `/en/ola` é o inglês; `rotasI18n` traduz os caminhos): a variável `idioma` e o `lang` do documento seguem a rota, e o `<head>` leva `<link rel="alternate" hreflang>` para cada idioma. `tenant.idiomas` (só com mais de um idioma) é a lista `[{ idioma, href, atual }]` para montar o **seletor de idioma** na página, com os rótulos vindos do catálogo (`idioma.en`).

## Links no idioma da requisição
Os caminhos internos da página precisam manter o idioma: `tenant.prefixo` é `""` no idioma padrão e `"/en"` nos demais, e os templates montam `{tenant.prefixo + "/produtos"}`. Sem isso, um clique no idioma inglês levaria à página em português (e, com `soConsulta`, o runtime não reconheceria o link como "da mesma página").

## Blocos e rótulos
Um bloco **não tem texto fixo que o template não possa trocar**: o template passa os rótulos já traduzidos. Os blocos de commerce aceitam `idioma` (formato do preço) e rótulos (`rotuloLink`, `rotuloFoto`, `rotuloIndisponivel`, `rotuloDe`, `rotulos` no resumo do pedido); sem eles, valem os textos em português de antes.

## Limites
Sem negociação por `Accept-Language` (quem entra sem prefixo vê o idioma padrão), sem formatação de datas por idioma (`data` é pt-BR) e sem moeda diferente de reais. As mensagens dos erros de validação do Polaris continuam em português (os formulários têm as próprias `mensagens` por idioma: `docs/formularios.md`).
